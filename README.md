# Eventify — Responsive Event Management Website

Eventify is a responsive front-end event management website built with HTML5, CSS3 and vanilla JavaScript.

## Features

- Responsive homepage with hero section
- Upcoming event cards
- Search and category filtering
- Event details modal
- Registration form with validation
- Registration confirmation ID
- LocalStorage registration persistence
- Dark/light mode
- Responsive mobile navigation
- FAQ section
- Accessible labels, modal roles and keyboard Escape handling
- No external libraries or API keys required

## Deployment

The project is a static website and can be deployed with GitHub Pages, Netlify or Vercel.

## Important note

This is a client-side demo. Registrations are stored in the browser's LocalStorage and are not submitted to a real backend/database.
